# 🌡️ Conversor de Temperatura Celsius para Fahrenheit (Java)

Este projeto consiste em uma aplicação de terminal desenvolvida em Java, com foco em conversão de unidades, manipulação de variáveis de ponto flutuante e operações aritméticas.

## 📖 Descrição do Projeto
O programa solicita ao usuário um valor de temperatura em graus Celsius (°C) via terminal, aplica a fórmula de conversão matemática e exibe a temperatura equivalente em Fahrenheit (°F).

## 🛠️ Recursos e Conceitos Aplicados
- **Entrada e Saída de Dados:** Uso da classe `java.util.Scanner` para captura de dados no terminal e exibição de mensagens formatadas.
- **Tipos de Dados Primitivos:** Utilização do tipo `double` para lidar com precisão decimal em valores de temperatura.
- **Operações Aritméticas e Fórmulas:** Aplicação da fórmula matemática de conversão $F = (C \times 1.8) + 32$.
- **Boas Práticas de Recursos:** Encerramento do leitor com o método `sc.close()` ao final da execução.

## 🚀 Como Executar
1. Certifique-se de ter o Java JDK instalado em sua máquina.
2. Clone este repositório ou navegue até a pasta do projeto.
3. Execute o arquivo via terminal ou pela sua IDE (IntelliJ IDEA):
   ```bash
   java ConversorTemperatura.java
