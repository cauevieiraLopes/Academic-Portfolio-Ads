# ➕ Calculadora de Soma com Funções (Java)

Este projeto consiste em uma aplicação de terminal desenvolvida em Java, com foco em modularização de código, declaração e invocação de métodos (funções) e passagem de parâmetros.

## 📖 Descrição do Projeto
O programa exibe uma mensagem de boas-vindas na tela, solicita ao usuário a digitação de dois números inteiros via terminal e utiliza uma função dedicada para realizar a soma e exibir o resultado formatado.

## 🛠️ Recursos e Conceitos Aplicados
- **Modularização (Métodos/Funções):** Separação de responsabilidades em funções auxiliares (`welcome` e `sum`) fora do método principal `main`.
- **Passagem de Parâmetros:** Transferência dos valores lidos no `main` como argumentos para o método `sum(int x, int y)`.
- **Entrada de Dados (`Scanner`):** Leitura de números inteiros fornecidos pelo usuário via `System.in`.
- **Boas Práticas de Recursos:** Fechamento da instância do leitor com `sc.close()` ao finalizar a execução.

## 🚀 Como Executar
1. Certifique-se de ter o Java JDK instalado em sua máquina.
2. Clone este repositório ou navegue até a pasta do projeto.
3. Execute o arquivo via terminal ou pela sua IDE (IntelliJ IDEA):
   ```bash
   java ExercicioFuncao.java
