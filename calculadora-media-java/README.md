# 🧮 Calculadora de Média de Notas (Java)

Este projeto consiste em uma aplicação de terminal desenvolvida em Java, com foco em leitura de dados do usuário, operações aritméticas e manipulação de tipos numéricos de ponto flutuante.

## 📖 Descrição do Projeto
O programa solicita ao usuário a inserção de três notas escolares via terminal, realiza o cálculo da média aritmética simples entre elas e exibe o resultado final de forma direta.

## 🛠️ Recursos e Conceitos Aplicados
- **Entrada de Dados (`Scanner`):** Utilização da classe `java.util.Scanner` para capturar os dados digitados pelo usuário no terminal (`System.in`).
- **Tipos de Dados Primitivos:** Uso do tipo `double` para garantir a precisão na leitura e no processamento de números decimais.
- **Operadores Aritméticos:** Aplicação de operações de adição e divisão priorizadas com parênteses para o cálculo correto da média.
- **Estruturação de Código:** Organização do código em pacote (`package`) e uso do método principal `public static void main` como ponto de entrada da aplicação.

## 🚀 Como Executar
1. Certifique-se de ter o Java JDK instalado em sua máquina.
2. Clone este repositório ou navegue até a pasta do projeto.
3. Execute o arquivo via terminal ou pela sua IDE (IntelliJ IDEA):
   ```bash
   java CalcularMedia.java
